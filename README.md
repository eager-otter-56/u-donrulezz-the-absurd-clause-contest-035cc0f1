# The Absurd Clause Contest

One absurd clause hidden deep inside a terms-of-service agreement, written as deadpan legal boilerplate: the Agent may terminate the Agreement at any time, provided it first obtains written consent from itself — consent it has already refused 38 times.

`main.py` writes the clause to `entry.txt` in `MAKEFUN_OUTPUT_DIR` (default `/output`).
